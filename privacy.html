Privacy Policy

Last updated: November 26, 2026

What the app accesses

Shorts Uploader uses Google's YouTube APIs to access only the owner's own YouTube account, for two purposes:

  • uploading the owner's own videos to the owner's own channel, and
  • reading that channel's analytics (such as views and watch time).

It does not access any other Google data, and it does not access any other person's account.

How data is stored

The Google sign-in token is stored only on the owner's personal computer. It is never uploaded to a server. Analytics data read from YouTube stays on that same computer.

Sharing

Shorts Uploader shares no data with anyone. It does not sell, transfer, or disclose any data to third parties, and it does not use data for advertising.

Google API Services

Shorts Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token file on the computer removes the stored login.
